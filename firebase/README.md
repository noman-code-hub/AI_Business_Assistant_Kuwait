# firebase/

Firebase project assets:

| File / Folder | Purpose |
|---------------|---------|
| `firebase.json` | Emulators, hosting, functions wiring |
| `firestore.rules` | Default-deny skeleton |
| `storage.rules` | Default-deny skeleton |
| `firestore.indexes.json` | Composite indexes |
| `functions/` | Triggers, schedules, callables |
| `hosting/` | Hosting extras |
| `emulators/` | Local emulator helpers |

Primary REST API is `apps/api`. Functions complement async workloads.
